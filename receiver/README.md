# YG Sync Receiver

Aplicación Android destinada a las pantallas.

Responsabilidades:

- Registrar la pantalla.
- Conectarse al Master.
- Recibir comandos.
- Reproducir contenido.
- Informar posición de reproducción.
- Informar estado.
- Mantener sincronización.
- Recuperar la conexión automáticamente.
