# YG Sync Controller

Aplicación Android que funcionará como dispositivo Master.

Responsabilidades:

- Descubrir pantallas.
- Emparejar dispositivos.
- Mantener conexiones.
- Seleccionar videos.
- Controlar reproducción.
- Controlar pausa.
- Controlar posición.
- Controlar volumen.
- Sincronizar hasta 10 pantallas.
- Mostrar estado de cada pantalla.
