# YG Sync Protocol

Protocolo de comunicación entre el dispositivo Master
(celular) y los dispositivos Receiver (pantallas).

## Arquitectura

Master
→ Receiver 1
→ Receiver 2
→ ...
→ Receiver 10

## Comandos

- CONNECT
- PING
- LOAD_VIDEO
- PLAY
- PAUSE
- STOP
- SEEK
- SET_VOLUME
- SYNC
- DISCONNECT
